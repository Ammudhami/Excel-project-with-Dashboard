# Excel-project-with-Dashboard
An Excel-based Sales Performance Dashboard built to monitor and analyze the daily sales activity of 141 field sales executives across 8 regions in India (Mumbai, Delhi, Nagpur, Chennai, Pune, Patna, Ranchi, Surat).

Tech Used: Microsoft Excel (.xlsm), PivotTables, Macros (VBA), Conditional Formatting

Features:

📊 Interactive Dashboard — Highlights the Top 5 and Bottom 5 performers by total sales and target achievement percentage

📋 Raw Data Sheet — Tracks 5-day individual sales data (Day 1–5) for each executive with auto-calculated totals, target hit %, and gap from target

🗂️ Region-wise Coverage — Data spans multiple cities across India with unique employee codes (e.g., Mum-TCL001)
